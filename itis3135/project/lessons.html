JavaScript Basics

JavaScript is the programming language that makes websites interactive. It can respond to clicks, change content, and create a more dynamic user experience.

Variables

Variables are used to store information that can be used later in a program.

let name = "Mayar";
let level = "Beginner";

Functions

Functions let you group code together so you can reuse it when needed.

function greetUser() {
  console.log("Welcome to CodeStart!");
}

greetUser();

Events

JavaScript can respond to user actions such as clicking a button.

document.querySelector("button").addEventListener("click", function () {
  alert("Button clicked!");
});

Why It Matters

JavaScript brings websites to life by allowing pages to react to users.

CSS Basics

CSS is used to style the appearance of a website.

Colors

body {
  background-color: lightblue;
  color: #1e3a8a;
}

Text Styling

h1 {
  font-size: 2em;
  text-align: center;
}

Layout

.container {
  display: flex;
  gap: 20px;
}

Why It Matters

CSS improves the user experience and design of a website.

Learning in Action

Both JavaScript and CSS work together to create websites that are useful and interactive.
