JavaScript Basics

JavaScript is the programming language that makes websites interactive. It can respond to clicks, change content, and create a more dynamic user experience.

Variables

Variables are used to store information that can be used later in a program. 

let name = "Mayar";
let level = "Beginner";

Functions

Functions let you group code together so you can reuse it when needed. 

function greetUser() {
  console.log("Welcome to CodeStart!");
}

greetUser();

Events

JavaScript can respond to user actions such as clicking a button, hovering over an item, or submitting a form. 

document.querySelector("button").addEventListener("click", function () {
  alert("Button clicked!");
});

Why It Matters

JavaScript brings websites to life by allowing pages to react to users and update content without being static.

CSS Basics

CSS is used to style the appearance of a website. It controls colors, spacing, fonts, and layout.

Colors

CSS allows you to set background colors, text colors, and borders to improve design and readability. 

body {
  background-color: lightblue;
  color: #1e3a8a;
}

Text Styling

You can style text by changing the font, size, alignment, and weight to make a page easier to read. 

h1 {
  font-size: 2em;
  text-align: center;
}

Layout

CSS helps organize content using layout tools such as flexbox and grid to create neat and structured pages. 

.container {
  display: flex;
  gap: 20px;
}

Why It Matters

CSS improves the user experience by making a website visually clear, attractive, and easier to navigate.

Learning in Action

Both JavaScript and CSS work together to create websites that are useful, interactive, and visually appealing.
